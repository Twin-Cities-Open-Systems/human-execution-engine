# hee-ssh-send-keys(1)

```
usage: hee-ssh-send-keys [-h] [-source SOURCE] [-dest DEST] [--generate]
                         [--validity VALIDITY] [--gpg-key GPG_KEY]
                         [--key-path KEY_PATH]

options:
  -h, --help           show this help message and exit
  -source SOURCE
  -dest DEST
  --generate
  --validity VALIDITY
  --gpg-key GPG_KEY    GPG key to sign the receipt with
  --key-path KEY_PATH
```
