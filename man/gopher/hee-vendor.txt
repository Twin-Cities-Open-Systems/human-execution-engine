NAME
       hee-vendor - vendor HEE doctrine into a target repo, validator-safe

SYNOPSIS
              hee-vendor --target REPO_PATH [--hee HEE_REPO_PATH] [--branch NAME]
                         [--no-push] [--auto-amend]
              hee-vendor --check --target REPO_PATH [--hee HEE_REPO_PATH]
              hee-vendor help

DESCRIPTION
              Copies HEE doctrine into a target repo in a layout the governance
              validator accepts, then opens a branch carrying the change.

              Vendored mode writes:
                prompts/hee/          HEE prompts, excluding .cursor
                prompts/hee/docs/     HEE docs/specs
                docs/hee/             pointers + VERSION only, imperative-free
                docs/HEE_POLICY.md    pointer doc, imperative-free
                scripts/hee-check.sh  consumer-side check
                .cursor/prompts       derived directly; the consumer needs no script

              This CREATES AND OVERWRITES those vendored directories, then creates a
              branch (default chore/vendor-hee-policy) and pushes it. --no-push keeps
              the branch local.

              --check is a non-mutating audit. It computes the diff vendoring WOULD
              produce and changes nothing.

EXIT STATUS
              In --check mode:
                0   no drift
                2   drift detected
                >2  tooling error
              Otherwise:
                0   vendored
                1   no --target given, or an unknown argument
