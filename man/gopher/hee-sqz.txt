NAME
       hee-sqz - squeeze a loop's OK:/FAIL: lines into one JSON line

SYNOPSIS
              <command producing OK:/FAIL: lines> | hee-sqz
              hee-sqz help

DESCRIPTION
              Reads stdin and counts lines by their leading marker, emitting a single
              JSON object with the pass/fail ratio. It COUNTS, never infers: an
              unmarked line passes through uncounted rather than being guessed at.

                OK: NAME       counted as a pass
                PASS: NAME     same
                FAIL: NAME     counted as a failure, and NAME is listed
                ERROR: NAME    same
                anything else  ignored

              Real convention, not a guess: every loop iteration emits exactly one
              marked line. Written for the fleet-ops#244 branch-protection rollout --
              15/15, JSON-parseable, no scrollback to eyeball.

EXIT STATUS
              0 always -- the ratio is the output, not the exit code

EXAMPLES
              for r in $repos; do
                check "$r" && echo "OK: $r" || echo "FAIL: $r"
              done | hee-sqz
