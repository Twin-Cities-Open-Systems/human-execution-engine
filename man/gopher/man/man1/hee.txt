NAME
       hee - Human Execution Engine command dispatcher

SYNOPSIS
       hee [help | list]
       hee subcommand [args...]

DESCRIPTION
       hee  is  a  thin dispatcher. It is the checkout, not an installed tool‐
       chain:  ~/.local/bin/hee  is  a  symlink  to  ~/git/human-execution-en‐
       gine/tooling/bin/hee, and every subcommand is an executable next to it.
       Pulling  the  repo  is the update mechanism; there is no second copy to
       drift.

SUBCOMMANDS
       Built-in:

       help   Show help. Works after any verb, and nothing to the right of  it
              is executed.

       list   List every available subcommand, built-in and extension.

       lint   Validate HEE object envelopes.

       hooks install
              Install this repo's git hooks.

       git merge
              Mass review/approve/merge open PRs.

       ssh send-keys
              Distribute SSH keys between hosts.

       contract review
              Review contract objects.

EXTENSIONS
       Any  executable named hee-<cmd> in the target repo's tooling/bin or the
       tool repo's,  resolved  in  that  order  —  so  hee  check  runs  tool‐
       ing/bin/hee-check.   Run  hee  list  for the current set; it is derived
       from what is present, not from a list kept here.

FILES
       ~/.local/bin/hee
              The dispatcher on PATH; a symlink into the checkout below.

       ~/git/human-execution-engine/
              The checkout. tooling/bin/ holds every subcommand; tooling/heerc
              is sourced by ~/.bashrc and sets PATH and per-oper preferences.

       ~/.hee/index/_.yaml
              This oper's SOA anchor (hee-soa.v1):  host,  user,  machine  id,
              stool  hash.  Read by hee ver session for a human shell's signa‐
              ture tag.

       ~/.hee/current/
              Per-oper working state (the  SOA  legs  and  hashes  the  anchor
              refers to).

       ~/.hee/bin/
              Only present once hee tools-update has installed a pinned exter‐
              nal tool there. Not the dispatcher, not the subcommands.
