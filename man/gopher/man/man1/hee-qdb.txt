NAME
       hee-qdb - real quote search across a source document

SYNOPSIS
       hee qdb -source PATH -search TERM

DESCRIPTION
       Searches  a  real source text file (a roster/quote-log document such as
       WHO-WE-ARE.md) for lines matching TERM and prints real  matches  --  no
       fabricated quotes, no paraphrasing.

OPTIONS
       -source PATH
              Path to the source document to search.

       -search TERM
              Search term. Required.

EXAMPLES
              hee  qdb  -source  ~/.local/bin/WHO-WE-ARE.md  -search "counting
              fact"

IRSSI INTEGRATION
              QDB   =   "EXEC   -o   ~/.local/bin/hee   qdb   -source   ~/.lo‐
              cal/bin/WHO-WE-ARE.md -search"

       then /QDB TERM in a channel.
