NAME
       hee-inv-receipt - turn a receipt image into HEE inventory objects

SYNOPSIS
              hee-inv-receipt ingest IMAGE [--tcos-repo PATH] [--vendor TOKEN]
                                           [--store TOKEN]
              hee-inv-receipt help

DESCRIPTION
              OCRs a receipt image and writes, into the TCOS planning repo:

                - one inventory.purchase object
                - inventory.purchase_line objects, best-effort parsed
                - the raw OCR text, stored as evidence

              Line parsing is best-effort by design: a receipt is not a structured
              document, and a wrong line is worse than a missing one. The stored OCR
              text is the authority to re-check against.

OPTIONS
              --tcos-repo PATH  target repo. Default: $HOME/git/tcos-plan-private
              --vendor TOKEN    vendor tag. Default: unknown
              --store TOKEN     store tag. Default: unknown

EXIT STATUS
              0 ingested   2 missing dependency, or the target is not the expected repo

REQUIRES
              sha256sum, rg, perl, tesseract, date, exiftool
