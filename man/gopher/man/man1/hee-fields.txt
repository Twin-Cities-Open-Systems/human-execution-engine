NAME
       hee-fields - hee-fields command

SYNOPSIS
              hee-fields [-h] {audit,set,batch} ...

DESCRIPTION
              positional arguments:
                {audit,set,batch}
                  audit            which open issues are missing Roadmap fields, or are not
                                   on the Roadmap

              options:
                -h, --help         show this help message and exit

EXAMPLES
              hee fields audit 12
              hee fields set 12 Priority P1

              Not marked "# ci": every subcommand reads or writes a GitHub Projects v2
              board over the API, which a runner cannot reach deterministically.
