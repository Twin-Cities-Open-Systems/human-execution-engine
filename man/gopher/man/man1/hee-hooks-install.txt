NAME
       hee-hooks-install - install this repo's optional git hooks

SYNOPSIS
              hee-hooks-install [--repo PATH]
              hee-hooks-install help

DESCRIPTION
              Symlinks tooling/githooks/pre-commit into the repo's .git/hooks/. Both
              non-destructive and idempotent -- re-running it changes nothing.

                --repo   the repo to install into. Defaults to the repo containing
                         the current directory.

              A relative symlink is preferred so the hook keeps working if the
              checkout moves; an absolute one is the fallback when that fails.

EXIT STATUS
              0 installed   2 not in a git repo, or the hook source is missing

EXAMPLES
              hee hooks-install
              hee hooks-install --repo ~/git/some-repo

              Not marked "# ci": it writes hooks into a git repo's .git/hooks, a mutation,
              so there is no read-only run to prove.
