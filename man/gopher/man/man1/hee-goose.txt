NAME
       hee-goose - honk

SYNOPSIS
       hee goose

DESCRIPTION
       Prints HONK in italics and a goose. That is all it does.

       The goose is rendered with chafa(1), which uses the kitty graphics pro‐
       tocol where the terminal supports it. Set HEE_GOOSE_IMAGE to render an‐
       other image.

EXAMPLES
              $ hee goose
              HONK

       followed by the goose, drawn in the terminal.

ENVIRONMENT
       HEE_GOOSE_IMAGE
              Path to the image chafa renders instead of the shipped goose.

SEE ALSO
       chafa(1)
